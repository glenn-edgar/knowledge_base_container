# Scan Tree Builtin VFT Reference

## Overview

Virtual Function Templates (VFTs) are the computational nodes of the scan tree.
Each VFT reads from input buffers and writes a single boolean (0 or 1) to an
output position in a layer buffer. The engine evaluates all VFTs bottom-up,
level by level, in declaration order within each level.

There are two classes of VFT:

- **System** — implemented in `builtins.c`, linked at compile time. Covers
  logic, comparison, state, and protection functions.
- **User** — prototypes generated by codegen, implemented by the application.
  Used for domain-specific evaluation logic.

All VFTs share the same C function signature:

```c
uint8_t vft_func(uint8_t *state, const st_handle_t *h,
                 const st_input_desc_t *inputs, uint32_t n_inputs);
```

| Parameter | Purpose |
|-----------|---------|
| `state` | Per-node persistent byte. Survives across cycles. Used by fuse, latch. |
| `h` | Scan tree handle — access to all buffer data via `st_buf_data()`. |
| `inputs` | Array of input descriptors with `buf_id`, `start`, `count`, `role`. |
| `n_inputs` | Number of input descriptors. |
| **return** | 0 or 1 — written to the output position in the layer buffer. |

## Input Roles

Inputs are tagged with roles so VFTs can identify which input is which
regardless of array position:

| Role | Constant | Used by |
|------|----------|---------|
| DEFAULT | `ST_ROLE_DEFAULT` (0) | and, or, not, copy, range_check (value) |
| SET | `ST_ROLE_SET` (1) | latch |
| CLEAR | `ST_ROLE_CLEAR` (2) | latch, fuse |
| THRESHOLD | `ST_ROLE_THRESHOLD` (3) | k_of_n |
| BITS | `ST_ROLE_BITS` (4) | k_of_n |
| A | `ST_ROLE_A` (5) | gt, ge, eq, lt, le, range_check (low) |
| B | `ST_ROLE_B` (6) | gt, ge, eq, lt, le, range_check (high) |
| INPUT | `ST_ROLE_INPUT` (7) | fuse (trip signal) |

## Logic VFTs

### VFT_and

Output = 1 if ALL input bits are 1.

| | |
|---|---|
| **Inputs** | 1+ bool bits (contiguous range) |
| **Output** | 1 bit |
| **State** | Not used |

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_and, "output:0-1", "input_bits:0-4")
```

**C runtime:**
```c
uint8_t st_vft_and(uint8_t *st, const st_handle_t *h,
                   const st_input_desc_t *in, uint32_t n);
```

### VFT_or

Output = 1 if ANY input bit is 1.

| | |
|---|---|
| **Inputs** | 1+ bool bits (contiguous range) |
| **Output** | 1 bit |
| **State** | Not used |

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_or, "output:0-1", "input_bits:0-3")
```

### VFT_not

Output = inverted input.

| | |
|---|---|
| **Inputs** | Exactly 1 bool bit |
| **Output** | 1 bit |
| **State** | Not used |

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_not, "output:0-1", "input:0-1")
```

### VFT_copy

Output = input (pass-through). Used to route a single bit between buffers.

| | |
|---|---|
| **Inputs** | Exactly 1 bool bit |
| **Output** | 1 bit |
| **State** | Not used |

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_copy, "output:0-1", "source:3-1")
```

**Use case:** Copying a non-contiguous pin into a scratch buffer so it can
be combined with other pins in an AND or OR operation.

## Comparison VFTs

All comparison VFTs read two float values via roles A and B. Output is 1 bit.

### VFT_gt

Output = 1 if A > B.

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_gt, "result:0-1", "current:0-1", "threshold:0-1")
```

### VFT_ge

Output = 1 if A >= B.

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_ge, "result:0-1", "value:0-1", "minimum:0-1")
```

### VFT_eq

Output = 1 if A == B. (Exact float equality — use with caution.)

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_eq, "result:0-1", "measured:0-1", "expected:0-1")
```

### VFT_lt

Output = 1 if A < B.

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_lt, "result:0-1", "temperature:0-1", "max_temp:0-1")
```

### VFT_le

Output = 1 if A <= B.

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_le, "result:0-1", "pressure:0-1", "limit:0-1")
```

### VFT_range_check

Output = 1 if low <= value <= high. Three float inputs.

| Role | Parameter |
|------|-----------|
| DEFAULT | Value to check |
| A | Low bound |
| B | High bound |

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_range_check,
    "in_range:0-1",          -- output
    "pressure:0-1",          -- value (DEFAULT)
    "pressure_low:0-1",      -- low bound (A)
    "pressure_high:0-1")     -- high bound (B)
```

## Voting VFT

### VFT_k_of_n

Output = 1 if at least K of N input bits are 1. K is read from a buffer
at runtime, allowing dynamic threshold adjustment.

| Role | Parameter |
|------|-----------|
| THRESHOLD | K value (uint8_t, 1 element) |
| BITS | N input bits (contiguous range, 2+) |

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_k_of_n,
    "quorum_ok:0-1",         -- output
    "quorum_threshold:0-1",  -- K value
    "voter_bits:0-5")        -- N bits
```

**Use case:** 2-of-3 sensor voting, majority-rules redundancy.

## Stateful VFTs

### VFT_latch

Set/reset latch. Clear takes priority over set.

| Role | Parameter |
|------|-----------|
| SET | Set signal (1 bit) |
| CLEAR | Clear signal (1 bit) |

**State byte:** 0 = reset, 1 = set.

**Behavior:**
- Clear high → state = 0 (regardless of set)
- Set high (clear low) → state = 1
- Both low → hold previous state

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_latch,
    "alarm_latched:0-1",     -- output
    "alarm_trigger:0-1",     -- set
    "alarm_clear:0-1")       -- clear
```

### VFT_fuse

One-shot trip with operator clear cycle. Fires an action callback
immediately when the trip condition is detected — without waiting for the
behavior tree to observe and respond.

| Role | Parameter |
|------|-----------|
| INPUT | Trip signal (1 bit) |
| CLEAR | Clear signal (1 bit) |

**State machine (3 states in state byte):**

```
State 0 (intact):   input high → blow, fire action callback, output=1 → state 1
State 1 (blown):    output=1, clear high → state 2
State 2 (clearing): output=1, clear low → re-arm, output=0 → state 0
```

The clear cycle requires a full low→high→low sequence. This prevents
accidental re-arming from a stuck clear signal.

**Action callback:** Fires once at the moment the fuse blows. The function
receives the application's `user_handle` pointer set via `h->user_handle`.

```c
void on_my_fuse(void *user_handle);
```

The codegen generates a `{name}_fuse_actions.h` header with prototypes and
documentation for each fuse callback the application must implement.

**Lua DSL:**
```lua
dsl:instantiate_vft(vft.VFT_fuse,
    "pump_fused:0-1",        -- output (blown status)
    "overcurrent:0-1",       -- trip signal
    "fuse_clear:0-1",        -- clear signal
    "on_pump_fuse")           -- C callback function name
```

**C callback implementation:**
```c
void on_pump_fuse(void *user_handle)
{
    my_app_t *app = (my_app_t *)user_handle;
    app->pump_enable = 0;  /* immediate shutdown */
    log_event("pump fuse tripped");
}
```

## User-Defined VFTs

For domain-specific logic not covered by builtins.

### DSL Registration (Lua)

```lua
local VFT_my_check = vft.user_vft("my_check", {
    {name = "measured", type = "float", count = 1},
    {name = "setpoint", type = "float", count = 1},
})
```

Arguments to `vft.user_vft()`:

1. **Function name** — becomes C symbol `user_vft_my_check`.
2. **Input specification** — array of `{name, type, count}`. The codegen
   validates instantiation parameters against this spec and generates
   a documented prototype in `{name}_user_vft.h`.

### DSL Instantiation

```lua
dsl:instantiate_vft(VFT_my_check,
    "result:0-1",            -- output: 1 bit
    "sensor_reading:0-1",    -- input 0: maps to "measured"
    "target_value:0-1")      -- input 1: maps to "setpoint"
```

### C Implementation

```c
uint8_t user_vft_my_check(
    uint8_t *state,
    const st_handle_t *h,
    const st_input_desc_t *inputs,
    uint32_t n_inputs)
{
    (void)state; (void)n_inputs;
    float measured = ((const float*)st_buf_data(h, inputs[0].buf_id))[inputs[0].start];
    float setpoint = ((const float*)st_buf_data(h, inputs[1].buf_id))[inputs[1].start];
    return (measured >= setpoint * 0.9f && measured <= setpoint * 1.1f) ? 1 : 0;
}
```

**Data access pattern:** `st_buf_data(h, inputs[i].buf_id)` returns `void*`
to the buffer's current data. Cast to the declared type and index by
`inputs[i].start`.

**State byte:** Available for user VFTs that need persistence across cycles.
Initialized to 0. The application owns the semantics.

### Generated Header

The codegen produces `{name}_user_vft.h`:

```c
/* my_check
 * Inputs:
 *   measured (float, count=1)
 *   setpoint (float, count=1)
 * Access data: st_buf_data(h, inputs[i].buf_id) + inputs[i].start
 */
uint8_t user_vft_my_check(
    uint8_t *state, const st_handle_t *h,
    const st_input_desc_t *inputs, uint32_t n_inputs);
```

## DSL Parameter Format

All VFT instantiation parameters use the format `"buffer_name:start-count"`:

- **buffer_name** — name defined by `dsl:define_buffer()` in the current scope
- **start** — zero-based element offset
- **count** — number of elements

Examples:
- `"power_status:0-2"` — 2 bits starting at position 0
- `"motor_current:3-1"` — 1 float at position 3
- `"output:0-1"` — single output bit at position 0

## Generated Files

The codegen produces headers based on what the tree uses:

| Condition | File | Contents |
|-----------|------|----------|
| Always | `{name}.h` | Const data tables, buffer defines, includes below |
| User VFTs present | `{name}_user_vft.h` | User function prototypes with input docs |
| Fuses present | `{name}_fuse_actions.h` | Fuse callback prototypes with trigger/clear docs |
