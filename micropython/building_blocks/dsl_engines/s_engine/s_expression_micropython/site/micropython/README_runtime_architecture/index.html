MicroPython Runtime Architecture

Overview

The MicroPython runtime (mpy_runtime/) is a line-for-line port of the C s_engine. It operates directly on constant tuple structures generated by the DSL compiler, with no heap wrapping or tree walking overhead.

Execution Model

The execution model is identical to the C engine:

  1. External caller owns the tick loop -- the runtime never blocks or sleeps
  2. tick_once() enters through the root node and returns a result code
  3. Composite functions (sequence, fork, state_machine) invoke their children explicitly
  4. The program structure emerges from how functions evaluate their children
# Typical tick loop
while True:
    result = se_runtime.tick_once(inst, se_runtime.SE_EVENT_TICK, None)
    if result in (SE_TERMINATE, SE_FUNCTION_TERMINATE, SE_PIPELINE_TERMINATE):
        break
    if result in (SE_DISABLE, SE_FUNCTION_DISABLE, SE_PIPELINE_DISABLE):
        break

Node Tuple Format

Each node in the tree is a 10-element tuple, frozen in ROM:

N_FUNC_NAME     = 0   # "SE_SEQUENCE" (debug only)
N_FUNC_HASH     = 1   # 0xABCD1234 (FNV-1a 32-bit)
N_FUNC_INDEX    = 2   # Index into oneshot/main/pred function table
N_NODE_INDEX    = 3   # DFS pre-order index (for node_states lookup)
N_CALL_TYPE     = 4   # "m_call", "o_call", "p_call", "p_call_composite"
N_ORDER         = 5   # Child order within parent
N_PARAM_COUNT   = 6   # Number of parameters
N_POINTER_INDEX = 7   # Pointer array index (for pt_m_call) or None
N_PARAMS        = 8   # Tuple of param tuples: ((type, value, order), ...)
N_CHILDREN      = 9   # Tuple of child node tuples

N_FUNC_INDEX and N_NODE_INDEX are pre-computed by the generator, eliminating runtime lookup costs.

Tree Tuple Format

T_NAME           = 0   # "my_tree"
T_NAME_HASH      = 1   # FNV-1a hash
T_NODE_COUNT     = 2   # Total nodes (for node_states allocation)
T_POINTER_COUNT  = 3   # Pointer array size
T_RECORD_NAME    = 4   # Blackboard record name or None
T_DEFAULTS_INDEX = 5   # Constants index
T_NODES          = 6   # Tuple of root node tuples

Function Dispatch

Three function tables, indexed by N_FUNC_INDEX:

Call Type Table Signature Returns
m_call main_fns fn(inst, node, event_id, event_data) result code
o_call oneshot_fns fn(inst, node) None
p_call pred_fns fn(inst, node) bool

Functions are registered by name (case-insensitive) via register_fns(). The name is matched against the module's function tables to determine the index.

Instance State

Only mutable state lives on the heap:

inst = {
    "mod": mod,              # Module reference
    "tree": tree_tuple,      # ROM tree tuple
    "node_states": {         # Mutable per-node state
        0: {"flags": 0x01, "state": 0, "user_data": 0},
        1: {"flags": 0x01, "state": 0, "user_data": 0},
        ...
    },
    "blackboard": {},        # Shared state fields
    "user_ctx": None,        # Application context
}

node_states is indexed by N_NODE_INDEX. Each entry has: - flags: active, initialized, ever_init (bitmask) - state: function-specific state counter - user_data: function-specific scratch value

Result Code Propagation

Same as C engine -- three tiers:

Range Tier Meaning
0-5 Application Returned to caller as-is
6-11 Function Translated by parent composite
12-17 Pipeline Handled by immediate parent

File Layout

mpy_runtime/
    se_runtime.py              Core engine (new_module, invoke, tick, param accessors)
    se_builtins_flow_control.py  sequence, chain_flow, fork, while, cond, trigger_on_change
    se_builtins_dispatch.py      state_machine, event_dispatch, field_dispatch
    se_builtins_pred.py          and/or/not/xor, field comparisons
    se_builtins_oneshot.py       log, set_field, queue_event
    se_builtins_return_codes.py  18 fixed return code functions
    se_builtins_delays.py        tick_delay, time_delay, wait, wait_timeout, nop
    se_builtins_verify.py        verify, verify_elapsed_time/events
    se_builtins_stack.py         frame_allocate/free, stack_frame_instance
    se_builtins_spawn.py         spawn_tree, tick_tree, exec_fn, exec_dict_*
    se_builtins_quads.py         3-address arithmetic/logical instructions
    se_builtins_dict.py          load_dictionary, extract_*, store_ptr_*
    se_builtins_all.py           Convenience merge of all builtins
    se_stack.py                  Call stack (push/pop/frame management)
    se_runtime_spike.py          Slim single-file runtime for SPIKE Prime
