# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-XX-XX

### Added
- Initial release
- Arena allocator with offset-based addressing
- ARM 4-byte alignment support
- Virtual class pattern with vtable
- Static buffer support
- Cross-compilation support
- Comprehensive examples
- Full documentation

### Features
- Zero malloc mode
- Position-independent structures
- Serialization support
- Thread-safe when used correctly
- No GNU extensions
