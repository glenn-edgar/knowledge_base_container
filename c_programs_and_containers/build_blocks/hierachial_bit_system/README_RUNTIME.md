# Hierarchical Bitmap Runtime API Reference

## Overview

The Hierarchical Bitmap Runtime (`cfl_hbit`) provides the C implementation for managing hierarchical status trees in embedded systems. The runtime handles memory management, bit propagation, shadow buffering, and efficient error detection across tree-structured device hierarchies.

**Key Features:**
- Zero-overhead tree structure (all in ROM)
- Shadow buffer pattern for atomic updates
- Three buffer types: OR_LATCH, OR_MASK, AND
- Efficient parent-child propagation
- Controller pattern for PLC bank mapping
- Error collection with monitoring node attribution

## 1. Memory Model

### ROM vs RAM Separation

```c
┌─────────────────────────────────────────────────────────────┐
│ ROM (Generated by codegen, const data)                      │
├─────────────────────────────────────────────────────────────┤
│ - Node descriptors (parent, children, depth, is_leaf)       │
│ - Hash lookup tables (sorted for binary search)             │
│ - Arena layout info (offsets, sizes per node per buffer)    │
│ - Buffer configurations (type, sizes)                       │
│ - Root node list                                            │
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│ RAM (Allocated at runtime, mutable state)                   │
├─────────────────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ Instance Structure                                      │ │
│ │ - Pointer to ROM config                                 │ │
│ │ - Allocator callbacks                                   │ │
│ │ - Dirty node tracking bitmap                            │ │
│ └─────────────────────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ Buffer Arrays (per buffer type)                         │ │
│ │ - current[buf]  : Active bit values                     │ │
│ │ - shadow[buf]   : Pending writes                        │ │
│ │ - latched[buf]  : Latched bits (OR_LATCH only)          │ │
│ │ - mask[buf]     : Enable masks (OR_MASK only)           │ │
│ └─────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

### Memory Calculation

Total RAM per buffer:
- **OR_LATCH**: `arena_size × 3` (current + shadow + latched)
- **OR_MASK**: `arena_size × 3` (current + shadow + mask)
- **AND**: `arena_size × 2` (current + shadow)

Plus overhead:
- Pointer arrays: `4 × buffer_count × sizeof(void*)`
- Dirty bits: `⌈node_count / 8⌉` bytes

**Generated constant** in header:
```c
#define IRRIGATION_VALVES_RAM_SIZE 245  // Pre-computed by codegen
```

## 2. Instance Lifecycle

### Creating an Instance

```c
#include "cfl_hbit.h"
#include "generated_irrigation_valves.h"
#include "generated_irrigation_valves_data.h"

// Define allocator (use your own malloc/free or custom allocator)
static void* my_alloc(size_t size, void* ctx) {
    return malloc(size);
}

static void my_free(void* ptr, void* ctx) {
    free(ptr);
}

cfl_hbit_allocator_t allocator = {
    .alloc = my_alloc,
    .free = my_free,
    .ctx = NULL
};

// Create instance
cfl_hbit_instance_t* inst = cfl_hbit_create(
    &allocator,
    (const cfl_hbit_config_t*)&irrigation_valves_config);

if (!inst) {
    // Allocation failed
    fprintf(stderr, "Failed to create instance\n");
    return -1;
}
```

**What happens:**
1. Allocates instance structure via `allocator.alloc()`
2. Allocates RAM block of size `config->ram_size`
3. Partitions RAM into buffer arrays (current, shadow, latched, mask)
4. Initializes dirty tracking bitmap
5. Returns fully initialized instance

### Resetting an Instance

```c
// Reset all buffers to initial state
cfl_hbit_reset(inst);
```

**What happens:**
- All `current` buffers set to 0
- All `shadow` buffers set to 0
- All `latched` buffers set to 0
- All `mask` buffers set to 0xFF (all bits enabled)
- Dirty flags cleared

### Destroying an Instance

```c
// Free all allocated memory
cfl_hbit_destroy(inst);
```

**What happens:**
1. Frees RAM block via `allocator.free()`
2. Frees instance structure via `allocator.free()`
3. Instance pointer becomes invalid

**Important:** Always destroy instances to prevent memory leaks.

## 4. Shadow Buffer Pattern

### The Two-Phase Update Pattern

```c
void control_loop() {
    // === PHASE 1: Accumulate Changes in Shadow ===
    
    // Read from hardware, write to shadow
    for (int plc = 0; plc < NUM_PLCS; plc++) {
        uint8_t alarm_data[8];
        read_plc_alarms(plc, alarm_data);
        cfl_hbit_shadow_write(inst, ALARM_BUF, plc_nodes[plc], alarm_data, 8);
    }
    
    // Application logic writes to shadow
    if (pump_offline) {
        cfl_hbit_shadow_set_bit(inst, ALARM_BUF, PUMP_NODE, COMM_FAIL_BIT);
    }
    
    // === PHASE 2: Sync and Propagate (Atomic Update) ===
    cfl_hbit_sync_and_propagate(inst);
    
    // NOW all changes are visible and propagated up tree
    
    // === PHASE 3: Application Logic Reads Current ===
    if (cfl_hbit_read_bit(inst, ALARM_BUF, ROOT_NODE, 0)) {
        handle_global_alarm();
    }
    
    // Next cycle accumulates new shadow writes...
}
```

### Why Shadow Buffers?

**Without shadow buffers (direct writes):**
```c
// BAD: Inconsistent state during updates
set_bit(VALVE_1, ALARM);  // Propagates immediately
set_bit(VALVE_2, ALARM);  // Propagates again
set_bit(VALVE_3, ALARM);  // Propagates again

// Application reads mid-update - sees partial state!
if (read_bit(ZONE, ALARM)) {  // Might be true after VALVE_1 write
    // But VALVE_2 and VALVE_3 not updated yet!
}
```

**With shadow buffers (atomic updates):**
```c
// GOOD: All updates batched, then atomically applied
shadow_set_bit(VALVE_1, ALARM);  // Queued in shadow
shadow_set_bit(VALVE_2, ALARM);  // Queued in shadow
shadow_set_bit(VALVE_3, ALARM);  // Queued in shadow

// Atomic boundary
sync_and_propagate();  // All changes visible at once

// Application sees consistent state
if (read_bit(ZONE, ALARM)) {  // Sees complete update
    // All three valves updated
}
```

## 5. Propagation

### Sync: Shadow → Current

```c
void cfl_hbit_sync(cfl_hbit_instance_t* inst);
```

**What happens:**
1. Copies shadow → current for all dirty leaf nodes
2. For OR_LATCH buffers: `latched |= current` (latch on 0→1 edge)
3. Marks all ancestors of dirty leaves for propagation
4. **Does NOT propagate** - that's a separate step

### Sync + Propagate (Most Common)

```c
void cfl_hbit_sync_and_propagate(cfl_hbit_instance_t* inst);
```

**What happens:**
1. Calls `cfl_hbit_sync()` to copy shadow → current
2. Calls `cfl_hbit_propagate()` to recompute parent nodes
3. Clears dirty flags

**Use this in your control loop tick.**

### Propagate: Leaf → Root

```c
void cfl_hbit_propagate(cfl_hbit_instance_t* inst);
```

**What happens:**
Walks tree **bottom-up** (children before parents), recomputing parent bits:

**OR_LATCH:**
```c
parent_current = 0;
parent_latched = 0;
for each child {
    parent_current |= child_current;
    parent_latched |= child_latched;
}
```

**OR_MASK:**
```c
parent_current = 0;
for each child {
    parent_current |= (child_current & child_mask);
}
```

**AND:**
```c
parent_current = 0xFF;  // Start with all 1s
for each child {
    parent_current &= child_current;
}
```

### Propagate Single Tree

```c
void cfl_hbit_propagate_tree(
    cfl_hbit_instance_t* inst,
    uint16_t root_idx);
```

Propagates only nodes under specified root. Useful when you have multiple independent trees and only one changed.

### Sync Single Buffer

```c
void cfl_hbit_sync_buffer(
    cfl_hbit_instance_t* inst,
    uint16_t buf);
```

Syncs shadow → current for specific buffer only. Rarely needed (usually just use `sync_and_propagate()`).

## 7. Latch Operations (OR_LATCH)

### Understanding Latches

**OR_LATCH buffers have TWO arrays:**
- `current[]` - Active bit values (updated on sync)
- `latched[]` - Sticky bits (OR'd with current on each sync)

**Behavior:**
```c
// Time T0: Everything clear
current = 0, latched = 0

// Time T1: Alarm occurs (0 → 1 transition)
shadow_set_bit(node, bit);
sync();
// current = 1, latched = 1  (latched!)

// Time T2: Alarm clears (1 → 0 transition)
shadow_clear_bit(node, bit);
sync();
// current = 0, latched = 1  (still latched!)

// Time T3: Operator acknowledges
clear_latch_bit(node, bit);
// current = 0, latched = 0  (cleared)
```

### Read Latched State

```c
bool cfl_hbit_read_latched_bit(
    const cfl_hbit_instance_t* inst,
    uint16_t buf,
    uint16_t node,
    uint8_t bit);
```

```c
uint8_t cfl_hbit_read_latched_node(
    const cfl_hbit_instance_t* inst,
    uint16_t buf,
    uint16_t node,
    uint8_t* data,
    uint8_t max_len);
```

**Example:**
```c
// Check current state
bool active = cfl_hbit_read_bit(inst, ALARM_BUF, node, LEAK_BIT);

// Check if alarm ever occurred (even if now clear)
bool latched = cfl_hbit_read_latched_bit(inst, ALARM_BUF, node, LEAK_BIT);

if (latched && !active) {
    printf("Alarm occurred but has since cleared - needs acknowledgment\n");
}
```

### Clear Latch

```c
cfl_hbit_error_t cfl_hbit_clear_latch_bit(
    cfl_hbit_instance_t* inst,
    uint16_t buf,
    uint16_t node,
    uint8_t bit);
```

```c
cfl_hbit_error_t cfl_hbit_clear_latch_all(
    cfl_hbit_instance_t* inst,
    uint16_t buf,
    uint16_t node);
```

**Example: Operator Acknowledgment**
```c
// User clicks "ACK" button for specific alarm
void acknowledge_alarm(uint16_t node, uint8_t bit) {
    cfl_hbit_clear_latch_bit(inst, ALARM_BUF, node, bit);
    cfl_hbit_propagate(inst);  // Update parents
}

// User clicks "ACK ALL" for entire node
void acknowledge_all_alarms(uint16_t node) {
    cfl_hbit_clear_latch_all(inst, ALARM_BUF, node);
    cfl_hbit_propagate(inst);
}
```

## 8. Mask Operations (OR_MASK)

### Understanding Masks

**OR_MASK buffers have TWO arrays:**
- `current[]` - Active bit values
- `mask[]` - Enable/disable mask (1 = enabled, 0 = disabled)

**Propagation formula:**
```c
parent_bit = (child1_bit & child1_mask) | (child2_bit & child2_mask) | ...
```

**Behavior:**
```c
// Mask = 1 (enabled): Bit propagates normally
child_bit = 1, child_mask = 1
parent_bit = (1 & 1) = 1  ✓ Propagates

// Mask = 0 (disabled): Bit blocked
child_bit = 1, child_mask = 0
parent_bit = (1 & 0) = 0  ✗ Blocked
```

### Read Mask

```c
bool cfl_hbit_read_mask_bit(
    const cfl_hbit_instance_t* inst,
    uint16_t buf,
    uint16_t node,
    uint8_t bit);
```

```c
uint8_t cfl_hbit_read_mask_node(
    const cfl_hbit_instance_t* inst,
    uint16_t buf,
    uint16_t node,
    uint8_t* data,
    uint8_t max_len);
```

### Set Mask

```c
cfl_hbit_error_t cfl_hbit_set_mask_bit(
    cfl_hbit_instance_t* inst,
    uint16_t buf,
    uint16_t node,
    uint8_t bit,
    bool enabled);  // true = enable, false = disable
```

```c
cfl_hbit_error_t cfl_hbit_set_mask(
    cfl_hbit_instance_t* inst,
    uint16_t buf,
    uint16_t node,
    const uint8_t* mask,  // Byte array (1 bits = enabled)
    uint8_t len);
```

### Clear All Masks

```c
cfl_hbit_error_t cfl_hbit_clear_mask_all(
    cfl_hbit_instance_t* inst,
    uint16_t buf,
    uint16_t node);
```

Sets all mask bits to 0 (disables all propagation from this node).

**Example: Maintenance Mode**
```c
// Enter maintenance mode - suppress all alarms from VALVE_12
void enter_maintenance(uint16_t valve_node) {
    cfl_hbit_clear_mask_all(inst, ALARM_MASK_BUF, valve_node);
    cfl_hbit_propagate(inst);  // Alarms from this valve no longer propagate
}

// Exit maintenance mode - re-enable alarm monitoring
void exit_maintenance(uint16_t valve_node) {
    // Set all mask bits to 1
    uint8_t mask[8] = {0xFF, 0xFF, 0xFF, 0xFF, 0xFF, 0xFF, 0xFF, 0xFF};
    cfl_hbit_set_mask(inst, ALARM_MASK_BUF, valve_node, mask, 8);
    cfl_hbit_propagate(inst);  // Alarms now propagate again
}
```

## 10. Controller Pattern

### What is a Controller?

A `cfl_hbit_controller_t` provides a **PLC-centric view** of a subtree, mapping hardware banks to the bitmap hierarchy.

**Use when:**
- Multiple PLCs each control a bank of devices
- Each PLC reports status as packed byte array
- You want both flat and child-relative indexing

### Create Controller

```c
cfl_hbit_controller_t* cfl_hbit_controller_create(
    cfl_hbit_instance_t* inst,
    uint16_t root,    // Parent node (e.g., STATION_2)
    uint16_t buf);    // Buffer index

// Returns: Controller pointer, or NULL on failure
```

**Example:**
```c
// Create controller for STATION_2 alarms
cfl_hbit_controller_t* ctrl = cfl_hbit_controller_create(
    inst,
    IRRIGATION_VALVES_NODE_VALVE_STATUS_STATION_2_VALVE_STATUS,
    IRRIGATION_VALVES_BUF_ALARM_LATCHED);
```

**What gets computed:**
```c
typedef struct {
    cfl_hbit_instance_t* inst;
    uint16_t root_node;       // STATION_2
    uint16_t buffer_idx;      // ALARM_LATCHED
    
    uint16_t child_count;     // 3 (BANK_1, BANK_2, BANK_3)
    cfl_hbit_child_t* children;  // Child descriptors
    
    uint16_t leaf_count;      // 10 (total leaf valves under STATION_2)
    uint16_t* leaf_nodes;     // Array of leaf node indices
    
    uint8_t bits_per_leaf;    // 8 (bits per valve)
    uint16_t total_bits;      // 80 (10 leaves × 8 bits)
    
    // Memory management
    cfl_hbit_allocator_t allocator;
    uint8_t* ram;
} cfl_hbit_controller_t;
```

### Destroy Controller

```c
void cfl_hbit_controller_destroy(cfl_hbit_controller_t* ctrl);
```

### Flat Bitmap Indexing

**Map linear index → (node, bit):**

```c
int16_t cfl_hbit_controller_get_bitmap_node(
    cfl_hbit_controller_t* ctrl,
    uint16_t flat_idx,  // 0..total_bits-1
    uint8_t* bit);      // Output: bit index within node

// Returns: Node index, or -1 if out of range
```

**Use case: Scan all bits**
```c
// Iterate all alarm bits in STATION_2
for (uint16_t i = 0; i < ctrl->total_bits; i++) {
    if (cfl_hbit_controller_read_bit(ctrl, i)) {
        uint8_t bit;
        int16_t node = cfl_hbit_controller_get_bitmap_node(ctrl, i, &bit);
        printf("Alarm at flat index %u → node %d, bit %u\n", i, node, bit);
    }
}
```

### Child-Relative Indexing

**Map (child_index, child_bit) → (node, bit):**

```c
int16_t cfl_hbit_controller_get_node_bit(
    cfl_hbit_controller_t* ctrl,
    uint16_t child,      // Child index (0..child_count-1)
    uint16_t child_bit,  // Bit relative to child
    uint8_t* bit);       // Output: bit index within node

// Returns: Node index, or -1 if out of range
```

**Use case: Process PLC data banks**
```c
// Read 24 bytes from PLC 1 (controls BANK_1 = child 0)
uint8_t bank1_data[24];  // 3 valves × 8 bits/valve
read_plc(PLC_1, bank1_data, 24);

// Write using child-relative indexing
for (int bit = 0; bit < 24; bit++) {
    if (test_bit(bank1_data, bit)) {
        cfl_hbit_controller_set_child_bit(ctrl, 0, bit);  // Child 0 = BANK_1
    } else {
        cfl_hbit_controller_clear_child_bit(ctrl, 0, bit);
    }
}
```

## 11. Error Detection and Analysis

### Count Error Bits

```c
uint32_t cfl_hbit_count_error_bits(
    cfl_hbit_instance_t* inst,
    uint16_t root,      // Root of subtree to scan
    uint16_t buf,       // Buffer to check
    bool use_mask);     // For OR_MASK: count only masked bits

// Returns: Total number of set bits in all leaves under root
```

**Features:**
- **Tree pruning**: If parent has no errors, skips entire subtree (O(log n) pruning)
- **Mask support**: For OR_MASK buffers, optionally counts only masked bits
- **Works with all buffer types**: OR_LATCH, OR_MASK, AND

**Example:**
```c
// Count all alarms (ignoring mask)
uint32_t total_alarms = cfl_hbit_count_error_bits(
    inst,
    IRRIGATION_VALVES_NODE_VALVE_STATUS,  // Entire tree
    IRRIGATION_VALVES_BUF_ALARM_LATCHED,
    false);  // Don't apply mask

// Count only actionable alarms (applying mask)
uint32_t masked_alarms = cfl_hbit_count_error_bits(
    inst,
    IRRIGATION_VALVES_NODE_VALVE_STATUS,
    IRRIGATION_VALVES_BUF_ALARM_MASK,
    true);  // Apply mask

printf("Total: %u, Actionable: %u, Suppressed: %u\n",
       total_alarms, masked_alarms, total_alarms - masked_alarms);
```

### Collect Error Bits

```c
typedef struct {
    uint16_t node;              // Leaf node index
    uint16_t index;             // Bit index within node
    uint16_t monitoring_node;   // Monitoring node or 0xFFFF
    uint8_t  value;             // Always 1 for errors
} cfl_hbit_error_bit_t;

typedef struct {
    uint32_t count;
    cfl_hbit_error_bit_t* error_bits;  // Array of errors
} cfl_hbit_error_bits_t;
```

```c
cfl_hbit_error_bits_t* cfl_hbit_count_error_bits_and_get_bits(
    cfl_hbit_instance_t* inst,
    uint16_t root,
    uint16_t buf,
    uint16_t number_of_monitoring_nodes,
    uint16_t* monitoring_nodes,  // Array of monitoring node indices
    bool use_mask);

// Returns: Allocated structure, or NULL on failure
```

**Two-pass algorithm:**
1. **Count errors** (iterate all leaves, count set bits)
2. **Allocate array** (single allocation for all errors)
3. **Fill array** (iterate again, record node, bit, monitoring node)

**Monitoring node attribution:**
- Walks ancestor chain for each error node
- Matches against `monitoring_nodes` array
- **First match wins** (stops at first monitoring node found)
- Sets `monitoring_node = 0xFFFF` if no match

**Example:**
```c
// Define monitoring nodes (major subsystems)
uint16_t monitoring[] = {
    IRRIGATION_VALVES_NODE_VALVE_STATUS_STATION_1_VALVE_STATUS,
    IRRIGATION_VALVES_NODE_VALVE_STATUS_STATION_2_VALVE_STATUS,
    IRRIGATION_VALVES_NODE_VALVE_STATUS_STATION_3_VALVE_STATUS,
};

// Collect all errors with monitoring attribution
cfl_hbit_error_bits_t* errors = cfl_hbit_count_error_bits_and_get_bits(
    inst,
    IRRIGATION_VALVES_NODE_VALVE_STATUS,  // Root
    IRRIGATION_VALVES_BUF_ALARM_LATCHED,
    3, monitoring,  // 3 monitoring nodes
    true);  // Apply mask

if (errors && errors->count > 0) {
    printf("Found %u errors:\n", errors->count);
    
    for (uint32_t i = 0; i < errors->count; i++) {
        cfl_hbit_error_bit_t* err = &errors->error_bits[i];
        
        printf("  Node %u, bit %u", err->node, err->index);
        
        if (err->monitoring_node != 0xFFFF) {
            printf(" (monitored by node %u)", err->monitoring_node);
        }
        printf("\n");
    }
    
    // Free when done
    cfl_hbit_error_bits_destroy(inst, errors);
}
```

### Destroy Error Collection

```c
void cfl_hbit_error_bits_destroy(
    cfl_hbit_instance_t* inst,
    cfl_hbit_error_bits_t* error_bits);
```

Always destroy error collections to prevent memory leaks.

## 13. Complete Example

### Setup and Initialization

```c
#include <stdio.h>
#include <stdlib.h>
#include "cfl_hbit.h"

#include "generated_irrigation_valves.h"
#include "generated_irrigation_valves_data.h"

// Simple malloc/free allocator
static void* my_alloc(size_t size, void* ctx) {
    return malloc(size);
}

static void my_free(void* ptr, void* ctx) {
    free(ptr);
}

int main() {
    // Create allocator
    cfl_hbit_allocator_t allocator = {
        .alloc = my_alloc,
        .free = my_free,
        .ctx = NULL
    };
    
    // Create instance
    cfl_hbit_instance_t* inst = cfl_hbit_create(
        &allocator,
        (const cfl_hbit_config_t*)&irrigation_valves_config);
    
    if (!inst) {
        fprintf(stderr, "Failed to create instance\n");
        return 1;
    }
    
    printf("Created instance with %u nodes, %u buffers\n",
           inst->config->node_count,
           inst->config->buffer_count);
```

### Writing Status from PLCs

```c
    // Simulate reading from PLC 1 (controls STATION_1, BANK_1)
    uint8_t plc1_alarms[8] = {
        0x01,  // Valve 1: bit 0 (overcurrent)
        0x00,  // Valve 2: no alarms
        0x04,  // Valve 3: bit 2 (stuck_closed)
        0x00, 0x00, 0x00, 0x00, 0x00

    cfl_hbit_shadow_write(
        inst,

```

### Checking for Alarms

```c
    // Check if any alarms exist in entire system
    bool has_alarms = cfl_hbit_read_bit(
        inst,
        IRRIGATION_VALVES_BUF_ALARM_LATCHED,
        IRRIGATION_VALVES_NODE_VALVE_STATUS,  // Root
        0);

        // Drill down to find which station
        bool station1_alarm = cfl_hbit_read_bit(
            inst,
            IRRIGATION_VALVES_BUF_ALARM_LATCHED,
            IRRIGATION_VALVES_NODE_VALVE_STATUS_STATION_1_VALVE_STATUS,

            printf("STATION_1 has alarms\n");
        }
    }
```

### Using Controller

```c
    // Create controller for STATION_1
    cfl_hbit_controller_t* ctrl = cfl_hbit_controller_create(
        inst,
        IRRIGATION_VALVES_NODE_VALVE_STATUS_STATION_1_VALVE_STATUS,
        IRRIGATION_VALVES_BUF_ALARM_LATCHED);

           ctrl->child_count, ctrl->leaf_count, ctrl->total_bits);

    for (uint16_t i = 0; i < ctrl->total_bits; i++) {
        if (cfl_hbit_controller_read_bit(ctrl, i)) {
            uint8_t bit;
            int16_t node = cfl_hbit_controller_get_bitmap_node(ctrl, i, &bit);
            printf("Alarm at flat index %u → node %d, bit %u\n", i, node, bit);
        }
    }
```

### Error Collection and Analysis

```c
    // Define monitoring nodes (stations)
    uint16_t monitoring[] = {
        IRRIGATION_VALVES_NODE_VALVE_STATUS_STATION_1_VALVE_STATUS,
        IRRIGATION_VALVES_NODE_VALVE_STATUS_STATION_2_VALVE_STATUS,
        IRRIGATION_VALVES_NODE_VALVE_STATUS_STATION_3_VALVE_STATUS,
        IRRIGATION_VALVES_NODE_VALVE_STATUS_STATION_4_VALVE_STATUS,

    cfl_hbit_error_bits_t* errors = cfl_hbit_count_error_bits_and_get_bits(
        inst,
        IRRIGATION_VALVES_NODE_VALVE_STATUS,
        IRRIGATION_VALVES_BUF_ALARM_LATCHED,
        4, monitoring,
        false);  // Don't apply mask
    
    if (errors) {
        printf("\nCollected %u error bits:\n", errors->count);
        cfl_hbit_print_error_bits_by_node(inst, errors);
        
        // Process errors by monitoring node
        for (uint32_t i = 0; i < errors->count; i++) {
            cfl_hbit_error_bit_t* err = &errors->error_bits[i];
            
            if (err->monitoring_node != 0xFFFF) {

## Performance Characteristics

### Time Complexity

| Operation | Complexity | Notes |
|-----------|------------|-------|
| `read_bit()` | O(1) | Direct array access |
| `shadow_set_bit()` | O(1) | Write to shadow array |
| `sync()` | O(dirty leaves) | Copies only dirty nodes |
| `propagate()` | O(dirty ancestors) | Bottom-up tree walk |
| `find_node()` | O(log n) | Binary search on hash |
| `count_error_bits()` | O(leaves) worst case | Tree pruning helps |

### Memory Usage

**Per instance:**
- ROM (const): ~50-100 bytes per node (node descriptors, arena info)
- RAM: `buffer_count × arena_size × 2` + overhead
  - OR_LATCH: 3× arena_size (current, shadow, latched)
  - OR_MASK: 3× arena_size (current, shadow, mask)
  - AND: 2× arena_size (current, shadow)

**Example: irrigation_valves schema**
- 36 nodes, 3 buffers
- ROM: ~2KB (generated data tables)
- RAM: 245 bytes (computed by codegen)

### Best Practices

1. **Call `sync_and_propagate()` once per control cycle** at tick boundary
2. **Batch all writes** in shadow buffer before syncing
3. **Use tree pruning** - check parent before drilling into children
4. **Create controllers once** and reuse (don't create/destroy every cycle)
5. **Use generated constants** instead of runtime lookups
6. **Profile before optimizing** - tree depth matters more than node count

## Thread Safety

**The runtime is NOT thread-safe** by default. If using in multi-threaded environment:

1. **Option 1**: Protect instance with mutex
```c
pthread_mutex_t hbit_lock;

void update_alarms() {
    pthread_mutex_lock(&hbit_lock);
    cfl_hbit_shadow_set_bit(...);
    cfl_hbit_sync_and_propagate(...);
    pthread_mutex_unlock(&hbit_lock);
}
```

2. **Option 2**: Use separate instances per thread (no shared state)

3. **Option 3**: Single-threaded design (recommended for embedded systems)
