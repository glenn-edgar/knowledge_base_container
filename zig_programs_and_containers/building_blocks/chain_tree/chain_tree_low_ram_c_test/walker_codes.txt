Here are all the return codes from CT_ReturnCode and their purposes:
Return Codes
CT_CONTINUE = 0
Normal traversal - Visit this node's children, then siblings, continuing the full tree walk.
Example: Processing every node in the tree normally.

CT_SKIP_CHILDREN = 1
Skip children, continue with siblings - Don't visit children of current node, but continue processing its siblings.
Example: You find a "disabled" folder node and want to skip everything inside it, but continue with other folders at the same level.
A
├── B (return SKIP_CHILDREN here)
│   ├── D (skipped)
│   └── E (skipped)
└── C (still processed)

CT_STOP_BRANCH = 2
Stop current branch, continue siblings - Abandon this node and its children, move to next sibling.
Example: Similar to SKIP_CHILDREN but indicates you want to abandon the branch entirely rather than just skipping children.
A
├── B (return STOP_BRANCH here)
│   ├── D (skipped)
│   └── E (skipped)
└── C (still processed)

CT_STOP_SIBLINGS = 3 ⚠️ Currently broken
Stop processing siblings, return to parent - Stop processing remaining siblings at this level and pop back up to parent's level.
Example: You found what you're looking for among siblings, no need to check the rest.
A
├── B
│   ├── D (return STOP_SIBLINGS here)
│   └── E (skipped - D's sibling)
└── C (still processed - A's child, not D's sibling)

CT_STOP_LEVEL = 4
Stop at current level - Sets max_level to current level, preventing traversal deeper than this point. Current branch completes, but no deeper levels explored.
Example: You want to limit search depth dynamically, like "only search 3 levels deep from here."
Level 0: A (return STOP_LEVEL at level 1)
Level 1: B, C (processed)
Level 2: D, E, F (all skipped - beyond max_level)

CT_STOP_ALL = 5
Stop entire walk immediately - Halt traversal completely and return to caller.
Example: You found exactly what you need, no point continuing at all.
A
├── B
│   ├── D (return STOP_ALL here)
│   └── E (not processed)
└── C (not processed)

Usage Pattern
These are returned from your CT_ApplyFunc callback:
cCT_ReturnCode my_apply_func(
    void* user_handle,
    unsigned int node_id,
    unsigned int level,
    uint8_t* flags
) {
    if (found_target(node_id)) {
        return CT_STOP_ALL;  // Done!
    }
    
    if (should_skip_subtree(node_id)) {
        return CT_SKIP_CHILDREN;  // Skip this branch
    }
    
    return CT_CONTINUE;  // Keep going
}
